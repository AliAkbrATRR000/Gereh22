# گره (Gereh) — نمونه اولیه اندروید P2P

این پروژه یک نمونه آموزشی قابل ساخت برای چت متنی مستقیم TCP است؛ **نسخه تولیدی امن نیست**.

## ساخت
1. Android Studio را نصب کنید.
2. این پوشه را با گزینه Open باز کنید.
3. اجازه دهید Gradle همگام‌سازی شود.
4. گوشی اندرویدی را وصل کنید و Run بزنید؛ یا از Build > Build APK(s) خروجی بگیرید.

## روش آزمایش
- دو گوشی باید شبکه‌ای داشته باشند که اتصال ورودی مستقیم را اجازه دهد.
- روی گوشی اول نام مستعار را وارد و «شروع انتظار برای اتصال» را بزنید.
- IP قابل دسترس گوشی اول را در گوشی دوم وارد کنید و «اتصال مستقیم» را بزنید.
- پورت TCP شماره 8988 باید از اینترنت به گوشی اول قابل دسترس باشد. معمولاً اپراتورهای موبایل CGNAT دارند و اتصال ورودی ممکن نیست.
- QR فعلی فقط نام/شناسه را نمایش می‌دهد؛ IP را به‌صورت دستی ردوبدل کنید.

## محدودیت‌های مهم
- هیچ سرور مرکزی، رله، STUN یا TURN در این نمونه وجود ندارد.
- ارتباط فقط وقتی کار می‌کند که یک گوشی از نظر شبکه مستقیماً قابل دسترس باشد؛ بنابراین «از هر نقطه دنیا» تضمین نمی‌شود.
- این نمونه فعلاً فقط متن می‌فرستد؛ ارسال عکس/فیلم، گروه، تاریخچه پایدار، اعلان پس‌زمینه و بازیابی اتصال پیاده‌سازی نشده‌اند.
- داده‌ها در این نمونه رمزگذاری سرتاسری نشده‌اند. برای استفاده واقعی یا ارسال اطلاعات خصوصی مناسب نیست.
- برای محصول واقعی باید احراز هویت کلیدمحور، رمزگذاری استاندارد (مثلاً Noise Protocol)، مدیریت کلید، ضد replay، انتقال chunk فایل و تست امنیتی اضافه شود.
- مجوز دوربین برای اسکن QR درخواست می‌شود. اسکن QR در این نمونه نام را می‌خواند؛ اتصال IP همچنان دستی است.
